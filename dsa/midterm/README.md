# 数据结构与算法 A · 期中复习站

在线访问：<https://plen09.github.io/dsa/midterm/>

本站把《数据结构与算法 A》的七章课件、六次书面作业与解答、前三章习题讲解，以及作业安排中的 OJ 注意事项整理为离线友好的静态页面。无框架、无 CDN 依赖，`index.html` 可直接本地打开。

## 内容

- 159 个知识点、64 道题（含参考解答）、25 张速查表
- 737 页课件逐页文字，可跳转到对应 PDF 页面
- 覆盖 `hw1`–`hw6`、前三章习题讲解、课件例题与 OJ 判题说明
- 图论部分补充 Dijkstra、Floyd、Prim、Kruskal、AOE 关键路径手算例题

## 功能

- 全站搜索，按章节、内容类型、题目来源筛选
- “已掌握”勾选与进度保存（`localStorage`）
- 随机抽题自测、展开全部解答
- 课件原文逐页浏览与关键词过滤
- 深色模式、打印样式

## 目录

```
dsa/midterm/
```
